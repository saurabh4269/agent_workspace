# BRAIN research operator workspace

Offline WorldQuant BRAIN research factory for disciplined alpha development.

## Important

- No passwords, cookies, or API tokens belong in this repo.
- Private expressions are gitignored under `research/private/`.
- Submissions require explicit `APPROVE SUBMISSION <candidate_id>`.
- This environment has no authorized BRAIN API session; use the manual UI runbook.

## Start here

1. `research/00_status.md` — compliance status and defaults
2. `research/01_hypothesis_cards.md` — 15-candidate research queue
3. `research/02_manual_sim_queue.md` — simulation order
4. `research/04_runbook.md` — live UI steps after you sign in
5. `research/03_experiment_ledger.csv` — append-only results log
